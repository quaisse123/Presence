# Workflow Activation Premier Acces

1. L'utilisateur arrive sur la page Login.
2. Si c'est sa premiere connexion, il clique sur "Activer mon compte".
3. Page 1 Activation: il saisit son email universitaire en `@ensam-casa.ma`.
4. Un code PIN est envoye par email.
5. L'utilisateur saisit le PIN recu.
6. Si le PIN est correct: continuer l'activation.
7. Si le PIN est incorrect: afficher une erreur et inviter a contacter le professeur.


8. Page 2 Activation: formulaire des informations utilisateur.
9. Le prenom et le nom sont pre-remplis depuis l'email, avec possibilite de modification.
10. L'utilisateur saisit aussi le code Apogee et choisit sa filiere/groupe.
11. Verification d'appartenance a la filiere/groupe choisi.
12. Si oui: compte active.
13. Si non: refus avec le message "Vous ne faites pas partie de la filiere/groupe choisi".

## Regles de parcours

1. L'activation est obligatoire uniquement au premier acces.
2. Les comptes deja actives passent par le login normal.
